# 💌 Interactive Multi-Step Date Invitation

A beautiful, single-file interactive web application designed to send a personalized date invitation and gather preferences dynamically.

## ✨ Features
* **Interactive Twist:** Features a playful, growing "Yes" button and a shrinking, elusive "No" button to ensure a fun user experience.
* **Preference Gathering:** Multi-step forms to select dates, times, date vibes (e.g., cozy coffee walk, foodie adventure), and multiple food choices.
* **Confetti Celebration:** Triggers a dynamic full-screen confetti explosion upon successful submission.
* **Serverless Email Delivery:** Integrated directly with the EmailJS SDK to cleanly package and route all responses straight to a personal Gmail inbox without requiring a backend database.

## 🛠️ Tech Stack
* HTML5 / CSS3 (Custom Variables & Grid Layouts)
* Vanilla JavaScript (State management & DOM manipulation)
* Canvas Confetti API (Visual celebrations)
* EmailJS SDK (Serverless email routing)

## 🚀 How to Host on GitHub Pages
1. Rename your main file to `index.html`.
2. Push the code to a public GitHub repository.
3. Go to **Settings** > **Pages** inside your repository.
4. Under **Build and deployment**, set the source to **Deploy from a branch**.
5. Select the **main** (or `master`) branch and the `/ (root)` folder, then click **Save**.
6. Wait a minute, and GitHub will provide your live website link!
